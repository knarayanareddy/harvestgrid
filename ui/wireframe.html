Attribution rule

A supervisor can record only the supervisor-review event. The interface provides no control to sign a worker’s acknowledgment on that worker’s behalf.

Interaction and state annotations
  • Offline signed drafts remain labeled local until accepted by the server.

  • Revocation and reassignment preserve the audit history without exposing unrelated PII.

What happens on reconnect?

  1. Upload eligible local drafts with idempotency keys.
  2. Show server acceptance only after the authoritative response.
  3. Route conflicts to comparison; retain the local copy until resolved.
Interaction and state annotations
  • Retry never discards a local draft.
  • Storage-full/eviction warnings appear before data loss and name export options.
  • Conflict resolution requires an authorized choice, not last-write-wins by default.
