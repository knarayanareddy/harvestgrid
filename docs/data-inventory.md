## Not present or collected

No real Ring media/event, exact address/coordinates, access note, owner identity, real tree ROI, face/plate/person data, real volunteer identity, phone number, opt-in record, availability, real recipient information, real harvest weight, real donation receipt, live weather response, trained model artifact, or real coordinator decision is present. Fixtures use fictional identifiers, normalized polygons, synthetic pixel grids, and coarse geohash cells only; no real owner, organization, device, or participant is present, and no cultivar content beyond the checked-in draft is available. Restricted-location strings in source/tests are explicitly fictional and are not persisted in workflow snapshots. No database, broker, analytics, prompt log, media store, model artifact, or model training set exists; no ONNX file is checked in (`*.onnx` is Git-ignored) and no telephony provider account is referenced. Fixture phone numbers are obviously synthetic and are never dialled.

Future raw residential media requires separate revocable consent, ROI/exclusion masking, restricted server-to-server access, seven-day default deletion after extraction, and no analytics/training use without separate consent. Exact location and access notes require assignment-scoped, time-limited reveal.

`datasets/private/`, model artifacts, and common model-binary extensions are Git-ignored. Do not convert real residential media or coordinator records into test fixtures.
